## 模型选型结论

- 主力开发：`gpt-6-astra`（GPT-6 Astra）
- 备选：GPT-5.6 Sol
- 轻量任务：GPT-5.6 Terra / Luna / GPT-5 Thinking Mini
- 应用内配置：`DATAPULSE_AI_MODEL=gpt-6-astra`
- Enterprise 默认关闭 Astra，需管理员手动启用

## 关键架构决策

- 一个图表组件只绑一个数据来源。
- 跨源合并上移到上游（源库视图 或 上游接口），DataPulse 通过 HTTP API 数据集消费。
- 单张图表跨数据集 join 明确不做。
- 取消 12 组件硬上限，改为分区约束 + 总数组件 ≤ 40 + 密度检查。
- AI 做成编译期可选模块，关闭时入口隐藏、功能完整。
- 组件分三批扩充，先补大屏刚需。

## 使用节奏

每轮只喂一个批次，结束跑 `pnpm verify`。

| 轮次 | 批次 | 完成标志 |

| 1 | 批次 1 | 画像可用 + 类型推断测试通过 |
