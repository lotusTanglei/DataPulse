# 测试会话记录

## 会话约定

- 本窗口专门用于 DataPulse 前后端联调与测试。
- 用户明确开始测试后，先启动项目并确认前后端可访问状态。
- 测试过程中收到问题反馈时：记录现象、复现步骤、影响范围和初步定位；不直接修改代码。
- 只有用户明确要求“开始修复”或等价指令后，才汇总当前已记录的问题并统一修复。
- 修复完成后进行必要的前后端验证，并更新本文件中的处理结果。

## 测试范围与准备

本版用例覆盖当前版本的核心闭环：初始化/登录、数据源、SQL 查询、数据库/API/文件数据集、大屏编辑、AI 辅助、发布、独立播放和安全嵌入。

### 测试环境

- 前端：`http://127.0.0.1:5173`（或启动时实际输出的地址）
- 后端：`http://127.0.0.1:8000`
- 健康检查：`GET /api/health`，预期返回 `{"status":"ok"}`
- 浏览器：至少 Chromium；发布/嵌入相关场景再用一个 WebKit 或 Firefox 回归
- 测试账号：首次初始化时创建；密码使用不少于 10 位的专用测试密码
- 测试数据：仓库 `apps/web/e2e/fixtures/` 下的 CSV、中文 CSV、Excel、JSON、Parquet 和 `sales.sql`

### 执行规则

- 优先执行 P0；P0 任一失败时暂停后续发布验收并先记录问题。
- 每条用例记录实际结果、截图/录屏、浏览器控制台错误、失败接口和 `X-Request-ID`。
- 涉及删除、发布、轮换密钥的用例使用专用测试数据，不使用真实凭据或生产地址。
- “不泄露”类检查同时看页面文本、Network 请求、响应体、URL、Cookie、Local Storage 和 Session Storage。

## 本轮执行结果

### 2026-09-09 第二阶段目标环境收尾

- 跨浏览器：修正 Firefox reload 后保留面板滚动状态，并在人工核对 actual/diff 后为 Firefox/WebKit 建立独立 Darwin 编辑器基线；Firefox、WebKit、Chromium 最终完整复跑均为 16/16。其他播放快照继续共用原基线，没有无评审批量更新。
- 生产等价代理：发现容器未显式配置可信代理时，TLS 终止后的 HTTPS `Origin` 会与后端 HTTP scheme 不一致。新增 `DATAPULSE_FORWARDED_ALLOW_IPS`、安全 Nginx 参考配置和一次性容器审计工具；HTTPS 同源写请求、伪造转发头拒绝、客户端 IP、Secure 播放 Cookie、CSP/no-store/nosniff 及日志脱敏全部通过。
- 显示：在在线 3024×1964 Retina 屏和系统 Chrome 中完成 DPR 2 抽样；3840×2160、DPR 2 仿真无溢出且保持 16:9。人工查看首张仿真图时发现减少动效未禁用 ECharts 入场动画，修复后图表首帧完整，2 个单元测试和 2 个显示目标用例通过，未更新视觉基线。
