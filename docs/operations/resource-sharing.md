# 用户与资源共享

管理员在「用户管理」中创建账号并指定管理员、编辑者或只读角色。修改角色、停用账号或重置密码会使该账号现有会话立即失效；系统禁止停用或降级最后一个有效管理员。管理操作和资源授权变更可在身份审计中查看。

| 角色 | 可执行的操作 |
| --- | --- |
| 管理员 | 管理账号、系统设置、受信任插件安装，以及所有资源与共享 |
| 编辑者 | 创建资源；查看获授权资源；编辑和发布分别取决于资源授权 |
| 只读用户 | 查看获授权资源，执行只读查询与预览；不能创建、编辑、删除或发布 |

角色是权限上限。给只读账号授予「可编辑」或「可发布」也不会允许其写入。资源创建者拥有该资源；管理员和拥有者可以管理共享。获得编辑权限不会成为资源拥有者，也不会获得转授权能力。

## 共享操作

进入「资源共享」，选择资源类型和资源，再选择接收用户及权限。支持大屏、数据源、数据集、数据文件和媒体资源。

- **可查看**：查看、查询和预览资源。编辑者可以复制有查看权限的大屏，副本属于复制者。
- **可编辑**：包含查看，并允许修改或删除资源。数据源连接测试也要求编辑权限。
- **可发布**：仅适用于大屏，包含编辑，并允许发布、修改播放访问策略、生成显示密钥。

大屏的数据集、数据源、文件和媒体依赖必须分别共享。大屏授权不会授予这些资源的权限；数据集依赖也同样检查。例如，共享 SQL 数据集时还必须共享其数据源，共享文件数据集时还必须共享来源文件。大屏的草稿与已发布版本都会检查依赖。

如果依赖缺少授权，相关大屏或数据集会从接收者的列表隐藏，直接读取或查询返回与资源不存在相同的 404。请由拥有者检查依赖并补充授权。撤销授权后，下次请求即重新检查权限；已有浏览器画面不等于继续持有访问权限。

## 界面与连接配置

只读资源保留查询和预览入口，隐藏保存、删除、编辑连接及分享管理操作。只读账号打开大屏编辑地址会转到预览。权限读取失败或会话缺少角色时，不显示写入操作；所有写入仍由后端独立校验。

服务器上的 SQLite 文件只能由管理员注册、修改路径或使用原始配置测试。编辑者可以查询获共享的数据源；取得编辑权限后，可以重命名它并测试已保存的连接。编辑者的新建连接表单提供 PostgreSQL、MySQL / MariaDB 和 HTTP API。上传 CSV、Excel、JSON 或 Parquet 的文件流程仍可用于创建自己的文件数据集。

Studio 账号权限与独立播放／Embed 凭证分别校验。需要撤回已签发的播放访问时，还应在相应大屏的发布与访问配置中轮换或撤销播放凭证；撤回某个 Studio 用户的共享不会代替该操作。
