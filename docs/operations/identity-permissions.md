# 用户与资源权限

DataPulse Studio 使用本地账号、会话 Cookie 与 CSRF 校验。已有管理员升级后保留账号、密码和有效会话，角色为 `admin`；历史数据源、数据集、数据文件、媒体资源和大屏归其所有。新账号使用独立 ID，默认不获得历史资源。

## 角色与授权矩阵

| 操作 | 管理员 `admin` | 编辑者 `editor` | 只读用户 `viewer` |
| --- | --- | --- | --- |
| 创建资源 | 允许 | 允许，成为拥有者 | 拒绝 |
| 注册或修改服务器 SQLite 文件路径、测试临时 SQLite 配置 | 允许 | 拒绝 | 拒绝 |
| 查看资源、数据查询、文件预览、媒体下载 | 全部 | 自己拥有或被共享的资源 | 被共享的资源 |
| 修改、删除资源 | 全部 | 拥有者或至少 `write` | 拒绝 |
| 复制大屏 | 全部 | 可读取原大屏及依赖时允许，新副本归自己 | 拒绝 |
| 发布、修改访问策略、生成显示密钥 | 全部 | 拥有者或 `publish` | 拒绝 |
| 管理资源共享 | 全部 | 资源拥有者 | 拒绝 |
| 用户创建、角色调整、停用、密码重置、权限审计 | 允许 | 拒绝 | 拒绝 |
| 系统设置、语音供应商配置、用量与审计、嵌入 API Key、生态安装与卸载、备份 | 允许 | 拒绝 | 拒绝 |
| 生态目录、已安装插件文件 | 允许 | 允许 | 允许 |
| 应用模板、AI 分析/图表/大屏/编辑 | 允许 | 必须能读取所有引用资源 | 拒绝 |
| 语音供应商简表及声音列表 | 允许 | 仅启用且配置完成的供应商 | 拒绝 |
| 语音试听计划、排队、查询、取消自己的任务 | 允许 | 见下方语音限制 | 拒绝 |

共享权限按 `read` → `write` → `publish` 递增。`publish` 包含读取与编辑，但不会授予共享管理或账号管理权限。角色上限优先：给 `viewer` 授予 `write` 或 `publish`，仍只有读取权限。发布权限只对大屏的发布相关操作有意义。

未明确开放的管理端点默认只允许管理员。共享接收者可从启用账号目录中选择；该目录只返回账号 ID 和用户名。

## 共享依赖

在“资源共享”中选择资源、用户及权限后保存。大屏共享不会自动共享其数据源、数据集或媒体；必须分别授权。

例如，大屏使用数据集 A，A 使用数据源 B，同时引用媒体 C。接收者需要读取大屏、A、B 和 C；若 A 来自上传的数据文件，则还需要该文件的读取权限。草稿与发布快照中的引用都会检查。复制、保存、AI 请求、任意文档预览和数据查询同样检查引用，不能通过自行填写其他资源 ID 绕过权限。

无权访问与资源不存在均返回中性的 `RESOURCE_NOT_FOUND`。列表只返回可见资源；数据集和大屏还必须能读取所有传递依赖，缺失底层文件、数据源或媒体授权时不会返回定义、字段或名称。媒体分页及使用量统计也仅计算可见资源；接口不会通过资产引用列表透露不可见大屏的名称。媒体下载使用 `no-store`，每次后续下载仍需通过鉴权。

共享数据源的 `read` 允许该数据源的只读查询和结构浏览，并非行级或仅某个数据集的访问权限。使用已存凭据测试修改后的连接配置需要该数据源的 `write`，不能借只读共享把凭据发送到其他地址。

SQLite 的路径指向服务器文件，只有管理员可以创建此类数据源、提交 SQLite 配置更新或测试临时 SQLite 配置，避免编辑者用新资源 ID 指向其他人的文件。编辑者可查询管理员明确共享的数据源；对既有数据源拥有 `write` 时，可通过该数据源 ID 测试原连接，也可修改不涉及配置的名称等信息。

## 撤销与账号变更

撤销共享后，对方下一次读取、修改、查询或下载会被拒绝，即使此前已执行过查询。已有页面可能保留已经加载的内容，但不能继续调用受保护接口。

角色变化、启用状态变化、管理员重置密码都会撤销该账号的已有会话。停用账号不能登录。服务端在事务中保护最后一位启用管理员，并发停用或降级也不能移除最后一位管理员。用户自己修改密码时，沿用已有行为：保留当前会话，撤销其他会话。

Studio 协作权限与发布观看权限分别管理。共享撤销不会替代显示密钥轮换、访问策略修改或宿主 Ticket 管理；播放器和嵌入页面继续使用原有授权链路。

## 语音试听的限制

编辑者生成试听时，必须对当前大屏有编辑权限，指定的数字人组件必须存在且可见，并且能够读取该大屏引用的资源。可选供应商仅来自启用且配置完成的供应商目录；目录只返回 ID、名称、语言和默认声音，不返回地址、凭据、用量或健康状态。

试听计划归创建它的账号。即使另一位编辑者能编辑同一大屏，也不能枚举、执行或查询对方的私人试听计划和任务。排队、轮询及取消任务会重新检查屏幕和组件权限；撤销共享后这些请求随即失效。编辑者不能通过 `approved=true` 绕过管理员配置的人工审核。

生成的试听媒体在任务成功并被创建者读取后，登记给创建者；复用已有语音缓存时只授予必要的媒体读取权限。普通媒体共享仍单独管理。全局任务列表、诊断、语音 AI 文案接口、用量与审计只对管理员开放。

## 冲突与审计

两位用户保存同一个草稿时，都必须携带读取时的版本号。较旧版本返回 `SCREEN_REVISION_CONFLICT`（409）；编辑器停止自动保存并提示重新载入，避免覆盖他人的修改。

账号与共享变更写入权限审计，只记录动作、操作者、目标用户/资源、时间和请求 ID。审计不记录密码、密码哈希、供应商凭据或查询结果。管理员可在“用户管理”的权限审计区域查看最近记录。

## 本地验证与部署边界

本地回归覆盖旧库迁移、账号生命周期、最后管理员并发保护、跨用户访问、引用检查、语音作用域、共享撤销、文件下载和草稿冲突。真实企业宿主、公开域名/HTTPS、目标数据库、目标语音服务和持续运行验收仍需在具备条件的环境中执行；本地通过不代表这些目标环境 gate 已完成。
