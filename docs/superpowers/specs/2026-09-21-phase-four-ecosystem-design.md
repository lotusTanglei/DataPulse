# 第四阶段：受控市场与组件插件

状态：2026-09-21 首版实现设计。

## 产品边界

交付离线安装包与本实例目录，不建立公共交易服务。目录展示模板/组件包、来源、许可证、版本和 API 兼容性，支持管理员导入、详情、使用、版本并存和安全卸载。普通观看者不能安装代码。安装前明确同源插件为管理员信任的代码，错误边界不等于恶意代码沙箱。

## 包与存储

插件沿用 PluginManifest，补充向后兼容的许可证/说明/默认配置等元数据。ZIP 中 manifest.json、声明的 .mjs 入口及资源均必须使用规范的相对路径；拒绝绝对路径、父路径、重复成员、符号链接、超限文件、压缩炸弹、不兼容 API 及内置组件名称覆盖。先在私有临时目录校验与解包，再原子安装；同 ID/版本内容不可变。安装包哈希和元数据可审计。

模板包含受校验的 DashboardDocument 及显式依赖。导入应用时重映射屏幕和组件 ID、组件引用、数据集及资产引用；不携带凭据。不能可靠映射的外部数据引用必须明确指定映射并校验授权，拒绝静默绑定。无依赖的静态/mock 模板应开箱可用。

发布文档锁定精确插件版本。升级以安装新版本开始，已有草稿/发布不自动迁移。需要迁移时显式产生可预览的草稿，支持保留旧版本回退；被引用版本不能卸载。模板包安装与创建屏幕分离，创建遵循资源权限。

## 前端 SDK

新增 `packages/plugin-sdk`，提供插件定义、组件 metadata、props/data 合同、渲染生命周期及显式配置迁移接口。使用普通 ES module，插件向受控 DOM 容器渲染，不要求宿主暴露 Vue 内部实例。组件收到受控 QueryResult、配置与取消信号，销毁时释放资源。

插件加载器依照服务端给出的精确包版本与入口加载，编辑器组件库与属性表单使用声明的配置 Schema。发布、独立播放与 Embed 都通过同一运行时宿主加载；鉴权后的发布资源接口只服务当前文档实际依赖的插件文件。加载/渲染错误仅降级该组件。

交付一个使用受控 QueryResult 的示例指标插件、构建和打包命令，覆盖编辑器添加、配置、发布及两种播放方式。

## 验收

包遍历/损坏/兼容性/权限/原子失败、安装与卸载引用保护、精确版本播放、插件缺失及错误隔离、模板引用重映射、schema 属性校验、发布后升级不改变旧版本、示例实际构建与三浏览器回归。
