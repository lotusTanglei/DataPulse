# 编辑器与数据源体验修复设计

## 背景

当前版本已经具备工作台、数据源管理、大屏编辑与发布能力，但真实自测暴露出几类会阻断使用的问题：编辑器在缩放画布上拖拽不跟手；发布成功后缺少独立播放和嵌入指引；MySQL/MariaDB 的 Schema 查询在部分版本失败；数据源凭据会被浏览器自动带入；点击表只能看字段而不能预览行；同时还缺少可复用的 HTTP API 数据源。

## 目标与非目标

目标是把这些问题收敛成可测试的基础能力：

1. 编辑器交互在 50%～150% 画布缩放下仍实时跟手，结束时只提交一次逻辑坐标。
2. 发布成功后提供独立播放 URL、复制/打开操作和嵌入说明。
3. Schema 元数据查询兼容 MariaDB，并提供安全的表数据预览。
4. 创建/编辑数据源时不再让浏览器把工作台管理员凭据填进数据库账号密码。
5. 支持 HTTP/HTTPS JSON API 数据源，并复用现有 QueryResult、刷新和图表链路。

非目标：本批不引入多用户协作、复杂 RBAC、模板市场或设备管理；发布页面的查看权限仍由宿主系统负责。

## 设计决策

### 编辑器

Moveable 挂在未变换的根容器上，画布自身继续负责视觉缩放；同步 Moveable 的 `zoom` 并在拖动/缩放过程中直接写入目标元素样式，`dragEnd`/`resizeEnd` 再把最终值转换成画布逻辑坐标提交。这样视觉反馈不等待 Vue store 更新，也避免 CSS transform 改变事件坐标系。Selecto 使用同一未变换根容器。

### 发布

发布接口成功后保持页面上下文不变，打开“使用方式”面板。独立播放使用后端 display key 生成的 URL，嵌入场景展示 iframe 示例和宿主后端获取短期 ticket 的说明；不会在查看页面自动轮换长期 embed API key。

### SQL 数据源预览

Schema 浏览器只发送数据源 ID、命名空间、关系名和限制条数。后端通过已发现的关系校验并由连接器安全引用标识符，返回统一 `QueryResult`；前端默认展示字段和最多 100 行，错误保留可读的连接器错误。

### HTTP API 数据源

HTTP API 是独立的 `http_api` 数据源类型，不伪装成 SQL 连接器。数据集查询定义保存 method、path/url、query、headers、JSON body、response path 和刷新策略。凭据仅在服务端加密保存，支持无认证、Bearer、API Key、Basic；请求只允许 HTTP/HTTPS，限制超时、响应大小、重定向和内网/云元数据地址，日志中不打印 token。

## 兼容性与迁移

现有 SQLite/PostgreSQL/MySQL 配置和 SQL/File 查询保持兼容；新增字段均为可选，旧的 `password` 密文继续可解密。HTTP API 首版只支持 JSON 到行数组的映射，后续可扩展分页和更多认证方式。

## 验证策略

每项先补充回归测试，再实现：后端运行针对性 pytest；前端运行组件测试、类型检查和构建；最后通过本地浏览器检查拖拽、发布指引、Schema 预览和 API 数据集完整链路。
